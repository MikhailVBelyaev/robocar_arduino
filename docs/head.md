# Голова Няни на серво машинки (команды /look, /nod, /status)

## Зачем
Проект «Няня» (домашний робот на Jetson Orin Nano) пока без шинных сервоприводов; первая «голова» — серво на пине 3
этой машинки (то же, что крутит дальномер). Няня поворачивает её на лицо и на голос. Раньше любой HTTP-запрос запускал
скан дальномером (~6 с блокировки) — для головы это непригодно, поэтому команды головы отвечают сразу.

## Команды (GET, порт 80)
| Команда | Что делает | Ответ |
|---|---|---|
| `/look?angle=N` | плавно повернуть на N градусов; N зажимается в 10…170 | `{"ok":true,"moved":bool,"target":..,"angle":..}`; без числа — 400 |
| `/nod` | кивок: ±10° два раза и назад | `{"ok":true,"started":bool}` |
| `/status` | состояние | `{"angle":..,"target":..,"ok":true,"uptime":сек}` |

Остальное (`/forward`, `/back`, `/left`, `/right`, прочие пути) работает как раньше, включая скан дальномером
(скан — единственное, что уходит за 10…170, до 180). Команды головы колёса НЕ трогают.

## Защита
- углы зажаты 10…170; нечисловой `angle` — ошибка 400, а не угадывание;
- шаг не больше 5° раз в 15 мс (`HEAD_STEP`, `HEAD_STEP_MS`) — без рывков и бросков тока;
- повтор той же цели серво не дёргает (`moved:false`); повторный `/nod` во время кивка игнорируется;
- без команд 60 с (`HEAD_IDLE_MS`) голова плавно возвращается в 90°;
- чтение запроса с таймаутом 200 мс: молчащий клиент не вешает голову;
- ответ уходит сразу, серво догоняет из `loop()` (`headTick`).

## Как прошить
Arduino IDE → плата Arduino Nano R4 (WiFiS3) → открыть `Arduino/WiFiCar/WiFiCar.ino` → Upload. Пароль Wi-Fi в файле
нужен ваш; IP смотреть в Serial Monitor (9600) — печатается раз в 10 с. Прошивку на этой стороне не компилировали
(компилятора нет) — при первой сборке возможны мелкие замечания компилятора.

## Как проверить curl'ом (IP — из Serial Monitor)
```
curl http://IP/status                 # {"angle": 90, ...}
curl "http://IP/look?angle=60"        # голова плавно влево/вправо, ответ сразу
curl "http://IP/look?angle=60"        # повтор: "moved": false, серво не дёргается
curl "http://IP/look?angle=300"       # зажмётся до 170
curl "http://IP/look?angle=abc"       # 400
curl http://IP/nod                    # кивок
```
Через 60 с без команд голова должна сама вернуться в 90. Колёса не должны шевелиться ни при одной команде.
